# VoiceShield API Documentation

This document describes the API endpoints exposed by the Node.js backend gateway and the Python FastAPI ML microservice.

---

## 1. Node.js Express Gateway (`http://localhost:5000`)

### 1.1 Analyze Audio Scan
- **Route**: `POST /api/analyze`
- **Payload**: `multipart/form-data`
  - `audio` (File, Required): Binary audio file (WAV, MP3, M4A, OGG).
  - `notes` (String, Optional): Custom analyst notes.
  - `scenario` (String, Optional): Force classification for Demo Mode (`genuine`, `synthetic_high`, `synthetic_med`).
  - `isDemo` (Boolean, Optional): Flags incident as mock metadata.
  - `language` (String, Optional): Locale for explainable summary (`en`, `hi`, `kn`).
- **Response**: `201 Created`
  ```json
  {
    "id": "c33b499d-12a8-43d9-9bbd-e30489b441ca",
    "timestamp": 1729012903001,
    "filename": "incoming_call_clip.wav",
    "result": "synthetic",
    "synthetic_probability": 0.94,
    "real_probability": 0.06,
    "confidence": 0.94,
    "risk_level": "high",
    "model_name": "VoiceShield-DeepfakeDetector",
    "model_version": "0.1.0",
    "processing_time_ms": 1120,
    "notes": "Finance caller verification.",
    "is_demo": false,
    "explanation": "Explanation narrative generated by Gemini...",
    "recommended_action": "High-risk caution directives..."
  }
  ```

### 1.2 Identity Verification comparison
- **Route**: `POST /api/verify`
- **Payload**: `multipart/form-data`
  - `reference` (File, Required): Registered speaker voice file.
  - `test` (File, Required): Incoming audio file.
- **Response**: `200 OK`
  ```json
  {
    "identity_match_score": 0.89,
    "synthetic_risk": "high",
    "synthetic_probability": 0.92,
    "real_probability": 0.08,
    "confidence": 0.92,
    "classification": "synthetic",
    "model_name": "VoiceShield-DeepfakeDetector",
    "model_version": "0.1.0"
  }
  ```

### 1.3 Register voice profile
- **Route**: `POST /api/register-voice`
- **Payload**: `multipart/form-data`
  - `name` (String, Required): Target speaker credentials.
  - `audio` (File, Required): Trusted voice sample file.
- **Response**: `201 Created`
  ```json
  {
    "id": "f8b9e110-3341-4c6e-8219-4cb88b1cc33e",
    "name": "Satya Nadella",
    "filepath": "references/f8b9e110-3341-4c6e-8219-4cb88b1cc33e.wav",
    "created_at": 1729012988102
  }
  ```

### 1.4 Get Incidents Log History
- **Route**: `GET /api/incidents`
- **Query parameters**: `includeDemo` (Boolean, default `true`).
- **Response**: `200 OK`
  ```json
  [
    {
      "id": "c33b4...",
      "timestamp": 1729012903001,
      "filename": "incoming_call_clip.wav",
      "result": "synthetic",
      "synthetic_probability": 0.94,
      "risk_level": "high",
      "is_demo": false
    }
  ]
  ```

### 1.5 Download PDF investigation report
- **Route**: `GET /api/incidents/:id/report`
- **Response**: Streams binary PDF download.

## 2. Python FastAPI ML Service (`http://localhost:8000`)

### 2.1 Analyze Audio Features
- **Route**: `POST /analyze`
- **Payload**: `multipart/form-data`
  - `file` (File, Required): Audio payload.
  - `scenario` (String, Optional): Preset classification overrides.
- **Response**: `200 OK`
  ```json
  {
    "classification": "synthetic",
    "synthetic_probability": 0.91,
    "real_probability": 0.09,
    "confidence": 0.91,
    "risk_level": "high",
    "model_name": "VoiceShield-DeepfakeDetector",
    "model_version": "0.1.0",
    "processing_time_ms": 1200
  }
  ```
